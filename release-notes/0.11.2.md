# OZ Shop 0.11.2

- LOOT and HYBRID trader offers now drain stock down to a target of zero. A positive percentage below one item removes one item per due tick, while `drainMax` and the target stock remain enforced.
- Trader stock changes only after a successful Wallet settlement.
- This release uses Java 25 and the Rising World PluginAPI 0.9.3.2 baseline.
