## Scope economy and trader reports

- Global shops, shop zones, and NPC traders now follow an independent, durable economy cadence even when no stock movement is due.
- Administrators can schedule the visible scope for an immediate scheduler pass. Open Shop overlays refresh after a stock-changing tick.
- Global-shop tick controls remain hidden when the global system shop is unavailable.
- Optional localized economy reports list item movements, trader name and position, balance, and profit or loss. Offers without an explicit currency use the configured shop or Wallet default currency.
- Read-only trader offer files now produce a clear editor error instead of a generic add failure.

Existing offers, stock state, trader data, and settings remain compatible.
