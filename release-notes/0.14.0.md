# OZ Shop 0.14.0

- Authorized managers can dress global and faction traders using a random outfit from the configured catalog or a copy of their currently worn clothing.
- The selection changes only the trader's clothing. It does not take items from the player or change the player's appearance.
- Trader clothing is saved in an additive SQLite table and restored after plugin reload or server restart. Existing traders keep their previous outfit until changed.

Keep the Shop database when updating. Faction traders require OZ - Factions 0.5.0 or newer. Requires Java 25 and Rising World PluginAPI 0.9.3.2.
