# OZ Shop 0.12.0

- Global system shops and plugin shops have independent switches and area overrides.
- Offer management uses separate tabs for each shop type.
- The redundant Shop enabled and Require shop zone controls are removed.

Existing world settings may still contain the old keys; they are ignored. Review the two global switches and area overrides after updating.

Requires Java 25 and the current Rising World PluginAPI.
