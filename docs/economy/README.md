# Shop Economy Docs

This folder contains the default system-offer economy rules used for generated Shop offers.

- [Shop Economy Classification](shop-economy-classification.md)
- [Shop Economy Raw Material Price List](shop-economy-raw-material-prices.en.md)

The checked-in `src/system-offers.complete.json` is the complete catalog generated from these rules plus the current placeholder-price review pass. The runtime `system-offers.default.json` is generated during the build from enabled T0-T11 offers only.
